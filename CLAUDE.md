# Project conventions

- Git commits in this repo must NOT include any Claude/Anthropic attribution —
  no `Co-Authored-By: Claude ...` trailer, no `Claude-Session: ...` line, and no
  mention of Claude/AI assistance anywhere in the commit message. Write commit
  messages as if a human wrote them.
- Commit messages must be a single short line (a subject only) — no body, no
  bullet points, no multi-paragraph description. Keep it under ~70 characters
  when possible.
